# Mapping L.A. neighborhood boundaries

`la-county-neighborhoods-v5.geojson` is the archived Los Angeles Times Data
Desk Mapping L.A. V5 boundary set, downloaded from the former
`boundaries.latimes.com` archive. Source repository:
https://github.com/datadesk/boundaries.latimes.com (snapshot commit
`1eaeafa3871e7237a89c2e1e59e6ff7d68fa97e0`).

`lantern-city-playable-v5.geojson` is a mechanically filtered snapshot of
features intersecting the existing Lantern City WGS84 viewport. Goldline owns
this versioned copy so production geography cannot drift with a remote service.
