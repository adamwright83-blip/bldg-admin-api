The handoff

Gumball succeeds when Chrome finishes the actual file in Gumball Inbox. Jawbreaker has a separate success/failure record for importing that artifact. Export success never means import success.

Gumball does not re-fetch the CSV, parse it, or keep an import transaction alive in this browser tab. The completed source file remains visible in Downloads/Gumball Inbox for Jawbreaker.
