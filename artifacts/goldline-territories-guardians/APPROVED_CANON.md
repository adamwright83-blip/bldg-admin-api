# Goldline Guardians — Approved Asset Pack

This is the ONLY approved guardian asset pack.

Use this sheet as the canonical visual reference for:
- Thunder King
- Cloud Duchess
- Sleepy One-Eye
- Tiny Emperor
- Gust Jester
- Drizzle Detective
- their props, attacks, veil/reveal effects, dialogue UI, and related guardian visual language

Important:
- Do not use or reference any earlier guardian packs.
- Preserve these silhouettes, personalities, and art direction.
- Treat this as the approved visual canon for the Territories & Guardians program.
- The actual in-game guardians should still be articulated/animated rather than used as static flat images wherever the implementation can support it.
