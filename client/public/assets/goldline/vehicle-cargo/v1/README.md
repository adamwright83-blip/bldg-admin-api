# Goldline Vehicle Cargo v1

Installed from the user-supplied Vehicle Cargo artwork attached to the Daily Line rebuild request. Source JPEGs have black matte backgrounds rather than alpha, so the layered home composition uses screen blending for the intended luminous transparent-car treatment.

Layer order: active/neutral glow, interior, authoritative cargo sprites, glass shell, labels and hit targets. Cargo sprites are never rendered without a custody record.
