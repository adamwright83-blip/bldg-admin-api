# BIO CONTAINMENT — mission asset pack

Canonical approved source art for the BIO CONTAINMENT mobile/driver Campaign Run /
Fiction Pack mission. These are the **approved source assets** for this mission —
do not regenerate, resize, recompress, or replace them without going back through
approval.

**Desktop assets are not part of this set.** These files are mobile/driver-surface
art only.

## Format note

The original asset plan specified `.webp` for the three large scene images
(`bio-containment-mission-hero`, `bio-containment-field-bg`,
`bio-containment-grid-complete`). The approved source files delivered were PNG, and
were intentionally preserved byte-for-byte as PNG rather than converted, so the
canonical source art stays untouched. Convert to WebP later during implementation
only if there is a concrete performance reason to.
