# Coastal Market proof: asset provenance

This covers the files in `client/public/assets/goldline/coastal-market-three-proof/`, and nothing
else. Every file there is either generated by a committed script in `scripts/assets/coastal-proof/`
or derived from the sources below. No file comes from Sketchfab, a store, a game, or any
unverified download.

## Generated here (owned outright)

| File | Made by | Notes |
| --- | --- | --- |
| `level.glb`, `level.json` | `scripts/assets/coastal-proof/build_level.py` | All level geometry (cliffs, route, stairs, bridge, buildings, props, sea stacks, lighthouse), built from numbers in Blender. |

The proof's brisk walk is derived from `Walk_Loop` at runtime (`runtime/character.ts`); no new
animation file is shipped for it.

The raw downloads live outside the repo in `~/Desktop/coastal-proof-sources/` (with `SOURCES.md`),
downloaded 2026-09-23 with Adam's permission. Only the files listed above are copied in.
