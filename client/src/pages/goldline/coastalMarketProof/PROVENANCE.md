# Coastal Market proof: asset provenance

This covers the files in `client/public/assets/goldline/coastal-market-three-proof/` and nothing else.
Every file there is generated by a committed script in `scripts/assets/coastal-proof/`, or derived from
the CC0 sources below. No file comes from Sketchfab, a store, a game, or an unverified download.

The raw downloads live outside the repo in `~/Desktop/coastal-proof-sources/` (see `SOURCES.md` there).
They were downloaded 2026-09-23 with Adam's permission, and only the derived files below are committed.

## Generated here (owned outright)

| File | Made by | Notes |

- The water, sky, fog, wind, waterfall and glow shaders were written for this proof. `clearwater` (MIT) was downloaded as a
  reference but nothing from it is used.
