# Coastal Market proof: asset provenance

This covers the files in `client/public/assets/goldline/coastal-market-three-proof/` and nothing else.
Every file there is generated by a committed script in `scripts/assets/coastal-proof/`, or derived from
the CC0 sources below. No file comes from Sketchfab, a store, a game, or an unverified download.

The raw downloads live outside the repo in `~/Desktop/coastal-proof-sources/` (see `SOURCES.md` there).
They were downloaded 2026-09-23 with Adam's permission, and only the derived files below are committed.

## Generated here (owned outright)

| File | Made by | Notes |
| --- | --- | --- |
| `level.glb`, `level.json` | `build_level.py` | All level geometry: cliffs, route, stairs, bridge, vaulted arch, buildings, props, sea stacks, lighthouse. Built from numbers in Blender. |
| `tex/lm_cliff.webp`, `tex/lm_town.webp` | `build_level.py --bake` | Cycles-baked AO + sun visibility of that geometry. |
| `tex/shore.webp` | `build_level.py` | Shallow-water mask ray-cast from the level. |
| `tex/water_normal.webp` | `prep_textures.py` | Generated ripple normals (a sum of sines). |
| `tex/sky.webp`, `tex/sky.json` | `prep_textures.py` | An authored sunset gradient. It carries cloud *detail* (local contrast) from a CC0 sky; see below. |
| skiff and sailboat in `props.glb` | `build_props.py` | Procedural hulls, parts and sail. |
| The phoenix tattoo image inside `trailblazer.glb` | `build_trailblazer.py` | Procedural line art. |
| All audio | `runtime/audio.ts` | Synthesized at runtime; no audio files. |

## Code

- `three` (MIT) and `three-mesh-bvh` (MIT) are npm dependencies.
- The water, sky, fog, wind, waterfall and glow shaders were written for this proof. `clearwater` (MIT) was downloaded as a
  reference but nothing from it is used.
